## 自動保存と手動保存

検索状態のブラウザー保存は行いません。変更をまとめて最初は約5秒後、以後原則30秒以上の間隔でDriveへ自動保存します。自動名はAuto_SL-Tour-Finder-Linden-search-YYYY-MM-DD_HH-mm-ss_UTC.jsonです。手動Drive保存とPCファイルの保存・読込は維持し、手動名は従来のJST日時付きです。

管理画面と通知の保存状態で進行・確認済み・失敗を確認します。未設定・権限不足・容量超過を保存済みと扱いません。再試行は同じ要求IDを使います。開き直した際は管理画面からJSONを選んで読み込みます。旧ブラウザー状態を自動復元しません。保存完了前のタブ終了では未保存変更が失われるため、確認済みの表示を確認して閉じます。ログイン・言語のブラウザー保存は別です。

## 保存先と共同作業

所有者限定は「保存先の変更」だけです。自動保存・Driveへの手動保存・一覧・読み込み・PCファイル操作は許可された全利用者が使えます。未設定の利用者は所有者の保存先を使い、既存の個人別保存先は保持します。このプロジェクトはTourDBに紐づくため、所有者はTourDBの所有者と同じです。実行者のメールではなく、本人確認済みアクセス者と照合します。[Googleの所有者の説明](https://developers.google.com/apps-script/guides/bound#access_to_bound_scripts)。

写真とは別のスタッフ共有フォルダーをおすすめします。実行所有者が読み書きでき、アクセス者本人または指定グループssj-sl-data-manager@googlegroups.comに編集共有されたフォルダーを使います。共有は運用担当者がDriveで設定します。アプリは共有を変更せず、公開・ドメイン共有や所有者だけのアクセス権をスタッフの許可にしません。

「検索設定 → 保存・再開 → 検索JSONの管理」または「設定 → 検索JSONの管理 → 開く」。専用ポップアップの保存先タブで、スクリプトの所有者だけがURLを変更できます。それ以外の利用者はURLを閲覧・コピーでき、入力は読み取り専用、変更ボタンはグレー表示です。サーバーも保存前に所有者を再確認し、画面を書き換えても変更を許可しません。変更前後は既存の確認履歴へ記録します。

保存済みタブで新規JSONへ保存します。既定名はSL-Tour-Finder-Linden-search-YYYY-MM-DD_HH-mm-ss_JST.json。保存内容を読み直して確認し、同じ保存要求の再試行は重複作成を防ぎます。一覧は30件ずつ取得し、名前・保存者・JST日時・サイズを表示。本文は明示的な読込時に取得します。

他スタッフの検索も同じDB・共有フォルダーから選択できます。対象名と置き換え確認にチェックして読み込みます。受け取り側の本人IDへ検索状態を関連付け、再検索・DB登録は行いません。形式・DB・保存者の識別・ファイルの版・内容の一致を確認し、不正・変更済みのデータを現在の検索へ適用しません。

Drive保存・読込上限4 MiB。PCファイルタブのダウンロード・読込は引き続き使えます。手動読込は64 MiB、同じ利用者・DBに限定します。共同引き継ぎはDrive一覧から行ってください。

検索条件・公開取得結果・選択・表示状態・続きの位置が対象です。候補DB・実施／確認履歴・写真・名簿・未保存メモ・認証情報は含めません。Driveへの自動保存失敗とJSON読込成功を区別します。プレビューはDriveに接続しません。
